# 珠宝海报生成器 · 腾讯云轻量服务器部署指南

> 目标：前后端分离的 AI 应用上线到腾讯云轻量服务器，使用宝塔面板 + Nginx + MySQL 5.7+（或 8.0）+ Node.js + PM2，绑定已购域名（HTTPS）。

## 0. 架构总览

```
用户浏览器 ──HTTPS──> Nginx (宝塔, 80/443, 你的域名)
                        ├── /            → frontend/dist（Vue 构建产物）
                        ├── /api/*       → 反向代理 → 127.0.0.1:3001（Express 后端）
                        └── /uploads/*   → 反向代理 → 127.0.0.1:3001（图片/Logo）
后端 Express：app.listen(PORT, '127.0.0.1') 只监听本机，不外泄 3001 端口（安全）
数据库：MySQL 5.7+（或 8.0），库名 haibao，导入 schema.sql + seed.sql
```

**关键点**：前端请求的 baseURL 是 `/api`，和后端在同一域名下 = 同源，后端 CORS 只放行 localhost:5173 也不影响生产。无需改任何前端/后端代码。

---

## 1. 服务器与宝塔准备

1. 确保服务器已装宝塔（SSH 登录后执行，装过可跳过）：
   ```bash
   wget -O install.sh https://download.bt.cn/install/install_6.0.sh && bash install.sh ed8484bec
   ```
2. 打开宝塔面板 → **软件商店**，安装：
   - **Nginx**（稳定版）
   - **MySQL 5.7+**（或 8.0）
   - **Node.js 18+**（建议 20 LTS）
   - **PM2 进程管理器**（或命令行 `npm i -g pm2`）

---

## 2. 上传代码

把本项目的 `backend/`、`frontend/`、`database/`、`data/`、`deploy/` 上传到服务器 `/www/wwwroot/haibao/`。

**上传方式任选**：宝塔「文件」管理器、FTP/WinSCP、或 `scp`。

⚠️ **不要上传**（用本机开发时的文件会指向本地 localhost，导致服务器连不上）：
- `backend/node_modules`（服务器上重新 npm install）
- `frontend/node_modules`
- `backend/.env`（本地开发配置，服务器会重新生成）
- `backend/data/settings.json`（本地 AI Key，优先级高于 .env，会覆盖服务器配置。首次部署建议清空或由服务器新建）

---

## 3. 创建数据库并导入数据

1. 宝塔 → **数据库** → 添加数据库：
   - 库名：`haibao`
   - 用户名/密码：自定（建议非 root，如 `haibao`）
   - 字符集：`utf8mb4`（项目用 utf8mb4_unicode_ci）
2. 导入表结构 + 种子数据。进 SSH，在项目目录执行：
   ```bash
   cd /www/wwwroot/haibao
   mysql -u haibao -p haibao < database/schema.sql
   mysql -u haibao -p haibao < database/seed.sql
   # 或使用迁移脚本（需 Node）：
   node database/run_migration.cjs
   ```

---

## 4. 一键部署（推荐）

在服务器项目目录执行部署脚本（已封装装依赖、生成 .env、构建前端、PM2 启动）：

```bash
cd /www/wwwroot/haibao
vim deploy/deploy.sh   # 先改 DB_PASS / AUTH_TOKEN 等变量
chmod +x deploy/deploy.sh
bash deploy/deploy.sh
```

之后手动补 AI Key：
```bash
vim /www/wwwroot/haibao/backend/.env   # 填 ARK_API_KEY / SILICONFLOW_API_KEY / DEEPSEEK_API_KEY
pm2 restart haibao-backend
```

脚本同时会做两件安全相关的事：
- 生成 `backend/.env`（600 权限，已存在则**跳过不截断**，保护手工填写的 AI Key）；
- 生成 `deploy/nginx-auth.conf`（600 权限），内容为 `proxy_set_header Authorization "Bearer <AUTH_TOKEN>";`，
  Nginx 在 `/api/` 反代时注入，浏览器端不接触令牌。

> 想手动一步步来，见第 5~8 节。

---

## 5. 手动安装后端依赖 + 生成 .env

```bash
cd /www/wwwroot/haibao/backend
npm install --production
```
创建 `.env`（参考项目里的 `.env.example`），**生产环境必填 AUTH_TOKEN**：
```bash
# 生成随机令牌
AUTH_TOKEN=$(openssl rand -hex 16)
```
在 `.env` 里填好：DB_HOST/PORT/USER/PASSWORD/NAME、PORT=3001、AUTH_TOKEN、以及三组 AI Key。

手动部署还需自建 Nginx 认证片段（一键部署由脚本自动生成）：
```bash
umask 077
printf 'proxy_set_header Authorization "Bearer %s";\n' "$AUTH_TOKEN" \
  > /www/wwwroot/haibao/deploy/nginx-auth.conf
```
令牌只存在于 `backend/.env` 与这个 600 片段中，前端代码和浏览器请求都不携带 token。

---

## 6. 构建前端

```bash
cd /www/wwwroot/haibao/frontend
npm install
npm run build
# 产物在 frontend/dist
```

---

## 7. 用 PM2 守护后端

```bash
cd /www/wwwroot/haibao
pm2 start deploy/ecosystem.config.js
pm2 save
pm2 startup        # 开机自启
pm2 logs haibao-backend   # 看日志
```

验证后端是否正常（生产模式开启认证，直连需带令牌）：
```bash
curl -H "Authorization: Bearer $AUTH_TOKEN" http://127.0.0.1:3001/api/health
# 期望：{"status":"ok",...}
```
> ecosystem.config.js 只放 NODE_ENV/PORT，令牌只在 `backend/.env` 与 Nginx 片段中。

---

## 8. 宝塔建站 + Nginx 反向代理

1. 宝塔 → **网站** → 添加站点：
   - 域名填你的域名
   - 根目录填 `/www/wwwroot/haibao/frontend/dist`
   - PHP 版本选「纯静态」（本项目无 PHP）
2. 用 `deploy/nginx-haibao.conf` 的内容替换该站点的「配置文件」。
   - 把里面的 `YOUR_DOMAIN` 换成你的域名
   - 确认 `root` 路径正确
   - `/api/` location 内的 `include .../deploy/nginx-auth.conf;` 保持不变（令牌注入点；`/uploads/` 不加认证，`<img>` 需要直连加载）
   - 保存后执行：`nginx -t && nginx -s reload`

---

## 9. 域名解析 + 开放端口

1. **域名解析**（在腾讯云/你的域名服务商控制台）：
   - 添加 A 记录：主机记录 `@`（及 `www`）→ 指向**服务器公网 IP**
   - 等待解析生效（`ping 你的域名` 能通即可）
2. **开放端口**：
   - 腾讯云轻量服务器控制台 → **防火墙**：放行 80、443（22 保持 SSH）
   - 宝塔 → 安全：放行 80、443
   - ⚠️ **不要开放 3001**（后端只走内网反向代理）

---

## 10. 配置 HTTPS（SSL）

宝塔 → 网站 → 站点 → **SSL** → 申请 Let's Encrypt 证书（选「域名」验证）→ 部署 → 开启「强制 HTTPS」。
部署后宝塔会自动给该站点包一层 443 server，反向代理配置保持即可。

---

## 11. 上线验收清单

- [ ] `curl https://你的域名/api/health` 返回 `{"status":"ok"}`
- [ ] 浏览器打开 `https://你的域名`，前端页面正常渲染
- [ ] 生成一张海报，确认 AI Key 有效、图片能上传、海报能返回 URL
- [ ] 认证闭环：浏览器 Network 面板里 `/api/` 请求**不带** Authorization 且不出现 401（令牌由 Nginx 注入）；直连 `curl http://127.0.0.1:3001/api/health` 应返回 401
- [ ] `pm2 status` 显示 haibao-backend 为 online，`pm2 logs` 无红色错误
- [ ] 磁盘监控：`data/uploads` 由定时任务按 24h TTL 清理；已保存项目引用的海报在 `data/posters`，**不会**被清理，需自行监控该目录增长

## 12. 常见问题

| 现象 | 排查 |
|------|------|
| 页面能开但接口 404/502 | Nginx 里 `/api/` 反代没生效；检查 `proxy_pass` 与后端是否在 3001 运行 |
| 后端启动报错要求 AUTH_TOKEN | `NODE_ENV=production` 时必须设 AUTH_TOKEN，改 .env 后 `pm2 restart` |
| 前端开了但全是 401 | Nginx 没注入或令牌不匹配：确认 `/api/` location 内 `include deploy/nginx-auth.conf;` 生效、片段里的 token 与 `backend/.env` 完全一致，改后 `nginx -s reload` |
| AI 生图失败 | 在设置页/`.env` 核对 ARK / SiliconFlow Key 是否有余额；看后端日志 `[Doubao]`/`[SiliconFlow]` |
| 上传图片 413 太大 | Nginx `client_max_body_size` 已设 100m；后端 multer 限制 10MB，超限按业务报错 |
| 图片/Logo 打不开 | Nginx 需反代 `/uploads/` 到后端，或确认 `data/uploads`、`data/logos` 目录可写 |
| 数据库连不上 | 核对 `.env` 的 DB_HOST=127.0.0.1、用户密码、库名；宝塔里确认 MySQL 已启动 |
